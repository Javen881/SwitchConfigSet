# SwitchConfigBatch 0.1

独立的批量改IP/配置导入工具。按“无厂家样本”设计：地址分配、占位符替换、预览、文件生成、Telnet/SSH会话和改址后验证均已实现；具体CLI语法在界面填写，不猜测厂商命令。

## Windows使用

Windows 便携包由 `packaging/` 中的脚本生成，输出到未纳入 Git 的 `dist/` 目录。若项目发布页提供 `SwitchConfigBatch-Windows-x64.zip`，完整解压后双击 `SwitchConfigBatch.exe`。无需安装Python，EXE必须和runtime/application目录一起保留。

默认Telnet、端口23（可修改）。SSH可选。第一次打开命令模板为空，不会发送任何命令。可以点击“载入离线演示”，体验三台设备的生成、模拟断线、新地址重连、身份匹配和IP回读；演示只使用内存模拟设备，不访问网络。

目标Windows 10/11 x64。便携包在Linux交叉生成，完成PE/文件/压缩包检查，未在Windows实机启动验收。默认任务数据目录为 `%LOCALAPPDATA%\SwitchConfigBatch`，启动异常记录在该目录 `startup.log`。

## 最短流程

1. 填写当前IP、起始新IP、数量、掩码和可选网关。
2. 粘贴或导入实际CLI文本。选中管理IP位置，点击“将选中文本替换为 ${IP}”；也可以手工输入占位符。不全局替换其他配置里的相同IP。
3. 填写设备身份查询及IP查询命令、对应提取正则。仅离线生成文件时可以留空；真实下发时需要这些规则。
4. 点击“生成预览”，按设备查看最终命令；可独立导出全部配置文件。
5. 在预览页填写Telnet账户、密码和连接参数，执行一台或顺序执行独立IP的全部设备。
6. 查看结果和完整回显。默认失败即停止后续设备，不自动重发配置。

## 占位符

| 占位符 | 含义 |
|---|---|
| `${IP}` | 当前设备的新管理IP |
| `${OLD_IP}` | 当前设备原管理IP |
| `${MASK}` | 点分十进制掩码 |
| `${PREFIX}` | 子网前缀长度，例如24 |
| `${GATEWAY}` | 指定网关；引用此变量时网关不可空 |
| `${INDEX}` | 从1开始的设备编号 |

仅替换显式占位符。未知占位符和不完整占位符拒绝生成；字面美元符号用 `$$`。空白命令行跳过，其他命令保持原文顺序，不将 `#` 自动当作注释。

生成地址在起始IP所在子网内递增，不跨子网；检查数量、掩码连续性、网络/广播地址、网关冲突以及清单内部的新旧IP冲突。不扫描网络，**不保证地址在实际网络未被其他设备使用**，执行前需要确认。

## 两种设备接入方式

- **逐台接入（相同出厂IP）**：当前IP填出厂地址。物理上一次只接入一台待配置交换机，选择对应编号后执行，完成后换下一台。真实协议下不允许一键执行全部同IP设备。
- **已有独立管理IP**：当前地址用逗号或空白分隔，数量和设备数一致且不得重复。顺序对应新地址清单，可以逐台自动处理；一台失败则停止后续设备。

本工具不支持利用ARP区分多台同IP设备，不包含厂家MAC定向修改协议。目标IP与当前清单中其他设备IP冲突时拒绝生成，不自动搬迁或交换地址。

## 两阶段CLI导入

**第一阶段：原IP会话**

先发送用户配置的只读身份查询，从回显提取序列号或稳定MAC。只有得到唯一非空身份值，才在同一会话中执行第一阶段配置。进入配置模式和退出等命令由用户显式填写。

**第二阶段：新IP会话**

按等待秒数延时后，以新IP建立新会话，再次查询身份。与第一阶段不一致时，立即停止，绝不继续向这个地址发送第二阶段配置。身份一致后才发送后续配置/保存命令，最后查询管理IP，要求提取结果与目标IP完全一致。

如果改IP立即断开：把改IP命令放在第一阶段最后一条，并启用“允许最后一条断连/超时后尝试核对”。只有前面的命令都完成、最后一条确已发送、状态为断连或超时，才进入新IP核对。中间命令失败、语法错误或未知确认提示不会触发自动继续。

如果设备要先保存/重启才生效，请自行按设备说明编排第一阶段并设置等待时间；需要按键确认或密码的交互会停止队列，不自动猜测回答。工具没有通用保存命令，也不会自动重启。第二阶段是新会话，不能依赖第一阶段配置模式仍在。

## 查询与正则

每个查询栏填写一条实际只读命令。提取正则必须有捕获组，第一捕获组是要比较的值。例如实际回显为：

```text
Serial: SW-001
Management IP: 192.168.1.101
```

相应提取规则可以是：

```text
(?m)^Serial: (\S+)\s*$
(?m)^Management IP: ([0-9.]+)\s*$
```

这是**回显格式示例**，不是对任何型号CLI命令或输出的保证。选择不会随管理IP变化的身份字段。捕获多个不同值或没有匹配值时停止，不从一大段配置中随意选第一个IP。

通用CLI提示符默认识别末尾的 `>` 或 `#`。按设备提示符调整；如使用 `[设备名]` 风格需另配精确规则。“高级CLI规则”提供分页、错误和未知交互的正则配置。只为已匹配分页标记自动发送空格，且记录辅助交互。SSH拒绝未知或变化的主机密钥，使用核验过的known_hosts文件。

## 数据与结果

- 保存方案JSON不含登录账户密码；模板本身可能包含用户自行输入的配置秘密，应按需保护。
- `generated/唯一ID/plan.json` 保存方案及设备映射；各设备有第一/第二阶段命令和查询文件。
- 每次设备尝试单独产生 `编号_随机ID_result.json`，再次尝试不会覆盖以前的结果。
- `logs/日期/任务ID/` 保存逐阶段命令、原始字节、可读回显、事件和结构化结果；原始证据独立于GUI显示窗口。
- “身份及管理IP核对完成”表示会话及两项回读符合规则，不代表整份配置各功能都验证过，也不代表重启持久化已验证。
- 超时、取消、断连均保留已收回显。取消不回滚设备侧已生效改动。
- 重启程序后遗留运行记录标为中断/待核对，绝不自动续发。原始目录入口可查看历史结果。
